🕵️ C'est quoi ?

HEIST.EXE transforme n'importe quel quartier en jeu d'espionnage grandeur nature. Papa crée la mission depuis son bureau. Le fils la vit dans les vraies rues.

Waypoints GPS réels, énigmes contextuelles, message audio crypté, countdown en temps réel via WebSocket… Tout ce qu'il faut pour qu'une sortie de quartier devienne une aventure inoubliable.

// GAMEPLAY LOOP

🎬 Comment ça marche

👨 PAPA — Coordinateur

1 Ouvre /admin
2 Entre la clé secrète
3 Crée mission : lore + waypoints GPS
4 Configure les énigmes à chaque point
5 Upload le message audio crypté 🎧
6 Envoie le lien + PIN 📲
→

📱 FILS — Agent de terrain

1 Reçoit le lien, ouvre l'app
2 Entre le PIN → Briefing crypté 🔐
3 Écoute le message audio secret
4 Navigue sur carte OpenStreetMap 🗺️
5 Trouve le waypoint → résout l'énigme 🧩
6 Mission accomplie → Récompense 🏆
// INTERFACE

📱 L'app en action

Boot → Map GPS temps réel → Énigme → Victoire
